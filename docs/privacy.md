# Privacy Policy for Tab Vault Pro

Tab Vault Pro does not collect, transmit, sell, or share personal data.

## Data Usage
All tab, window, and session data is stored locally within the Microsoft Edge browser using Edge's extension storage APIs.

If the optional sync feature is enabled, data is stored and synchronized using Microsoft Edge's built-in sync infrastructure.

## No Third-Party Access
Tab Vault Pro does not:
- Use analytics or tracking services
- Send data to external servers
- Share data with third parties
- Display ads

## Contact
If you have questions about this privacy policy, you may contact the developer via the GitHub repository.
